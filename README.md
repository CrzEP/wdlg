# gword
这是一个多功能、轻量级、开源的记单词应用。

主要特色是允许在命令行记单词，其次是开放API，允许多端使用。

这个应用是围绕单人进行设计，笔者不想对用户权限进行过渡开发，所以只有token作为身份辨识。

因为笔者需求是在上班期间记单词，所以会优先开发cli，其次开发其他部分。



## 模块拆解

api: 提供接口的服务模块

cli: 本地命令行模块。需要开发GUI的可以在此基础上开发。

core: 核心功能模块

## 开发指导

1. 主要帮助利用IT帮助个人快速度过记单词的学习阶段。
2. 其次提供记忆算法、CLI、多端通用随地记等减少背单词的麻烦提升效率。
